# 블로그 구조 (네이버 블로그)

## 방향
- 경영지원 노하우 · 엑셀 · 스타트업 일상으로 시작하고, 개인 일상은 별도 카테고리로 분리한다.
- 블로그가 자리 잡으면 체험단·후원 등 수익화를 검토한다.
- 회사 글과 개인 글은 카테고리를 나눠서 회사 정보가 섞이지 않게 한다.

## 카테고리 (4개)
| 카테고리 | 다루는 내용 | 글 유형 |
|---|---|---|
| 경영지원 노하우 | 월마감, 4대보험, 계약·증빙, 총무 실무 | 체크리스트형, 실수담형 |
| 엑셀 | 함수, 대사, 자동화, 서식 | 따라하기형, 비교형 |
| 스타트업 일상 | 일하는 방식, 도구, 회고 | 일기형, 회고형 |
| 개인 일상 | 공부, 취미, 여행, 소비 | 일기형, 후기형 |

## 발행 주기
- 시작은 주 1회, 화요일 발행을 기본으로 한다. 5~10주 해본 뒤 늘릴지 정한다.
- 4주 사이클: 경영지원 → 엑셀 → 스타트업 일상 → 개인 일상. 반응이 좋은 카테고리가 보이면 비중을 조정한다.

| 주차 | 발행일 | 카테고리 |
|---|---|---|
| 1 | 11/3(화) | 경영지원 노하우 |
| 2 | 11/10(화) | 엑셀 |
| 3 | 11/17(화) | 스타트업 일상 |
| 4 | 11/24(화) | 개인 일상 |

## 작성 흐름
`주제 은행에서 고르기 → Claude가 먼저 질문(경험·실패담·의견) → 초안 → 점검표 확인 → 비공개 발행 → Duke 확인 → 공개`

- 공개 전환은 Duke가 직접 말할 때만 한다.
- 발행 전 점검표(`checklist.md`)를 통과해야 한다.

## 파일
- `instructions.md`: Claude 프로젝트 지침 (복사해서 붙여넣기)
- `topics.md`: 주제 은행 40개
- `templates.md`: 글 유형별 구조
- `checklist.md`: 발행 전 점검표
