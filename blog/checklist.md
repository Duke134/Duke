# 발행 전 점검표

## 정보 보호
- [ ] 실명·연락처·계좌·급여가 없다
- [ ] 회사 내부 숫자(매출, 투자, 지분, 계약금액)가 없다
- [ ] 정부사업·지원사업의 선정·금액·과제명이 없다
- [ ] 사진·캡처에 얼굴, 사번, 거래처, 화면 속 회사 정보가 없다
- [ ] 개인 일상 글에 집 주소, 자주 가는 장소·시간대, 가족 정보가 드러나지 않는다

## 사실 확인
- [ ] 법·세무·노무 내용은 조문을 확인했거나 "(조문 미확인)"으로 표시했다
- [ ] 숫자와 날짜는 출처가 있다 (없으면 [확인 필요])
- [ ] 지어낸 경험이나 사례가 없다
- [ ] 외부 자료를 인용했으면 출처를 적었다
- [ ] 체험단·협찬 글이면 대가를 받았다는 표시가 첫머리에 있다 (표시광고법 관련, 조문 미확인)

## 글 품질
- [ ] 제목이 구체적이다 (무엇을 알게 되는지)
- [ ] 내 경험 또는 실패담이 한 가지 이상 들어 있다
- [ ] 금지 표현("다양한", "효과적으로", "~하는 것이 중요합니다")이 없다
- [ ] 최근 글과 길이·구성이 다르다
- [ ] 이미지 설명(대체텍스트)이 있다

## 발행
- [ ] 비공개로 먼저 올렸다
- [ ] Duke가 읽고 공개를 승인했다
