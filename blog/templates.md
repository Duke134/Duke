# 글 유형별 구조

## 체크리스트형 (경영지원)
1. 한 줄 요약: 이 글로 무엇을 끝낼 수 있는지
2. 내가 겪은 계기 (2~3문장)
3. 단계별 체크리스트 (5~8개)
4. 실수하기 쉬운 곳 1~2개
5. 확인할 곳 (기관·법령 이름만, 단정 금지)

## 실수담형
1. 무슨 일이 있었는지
2. 왜 틀렸는지
3. 지금은 어떻게 하는지
4. 같은 실수를 막는 한 줄

## 따라하기형 (엑셀)
1. 결과물 예시 (샘플 데이터로 만든 화면)
2. 준비물과 샘플 데이터
3. 단계 (함수는 그대로 복사 가능하게 코드로)
4. 자주 나는 오류와 해결
5. 응용 한 가지

## 비교형
1. 비교 기준 3개 정하기
2. 표로 비교
3. 내 선택과 이유 (경험 기반)

## 일기형 (일상)
- 소제목 없이 짧게. 장면 1~2개와 느낀 점 한두 줄.

## 회고형
- 이번 달 한 일 3개 → 아쉬웠던 것 1개 → 다음 달 바꿀 것 1개
